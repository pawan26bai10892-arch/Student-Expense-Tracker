# Project Statement

## Problem statement
People often lose track of where their money goes because expenses are scattered across notes, memory and receipts. There is a need for a simple, private tool to record and review spending.

## Scope
A single-machine command-line application with multiple user accounts, expense management, reporting and export. No web or mobile interface.

## Target users
Students and individuals who want a lightweight way to track daily spending.

## High-level features
1. Secure registration and login
2. Expense CRUD with validated input
3. Category filtering, summary and monthly reports
4. CSV export
5. Logging and automated tests

## Technology
Python 3, SQLite (sqlite3), unittest/pytest. Standard library only.
